# WebSSH SFTP 实施记录

状态：已部署测试环境，真实登录、目录浏览和页签状态保留已验收；上传下载及撤权验收仍待完成，不应视为生产就绪。

## 已实现

- 独立 `sftpfiles` 协议适配层，接受已鉴权并校验主机指纹的 SSH 连接。
- 目录列表及符号链接标识；只预览/下载普通文件。
- UTF-8 文本预览（最多 256 KiB），不接受二进制/NUL 内容。
- 32 KiB 缓冲流式上传下载，上传限额由调用方传入。
- 临时文件权限 0600，使用 `hardlink@openssh.com` 原子发布且不覆盖同名文件。
- 本地只读能力和远端文件权限共同生效。
- 每会话单操作并发限制，协商 10 秒、操作 5 分钟超时；取消关闭独立 SSH 连接。
- 实际 SFTP 客户端/服务端协议测试，不是文件操作 mock。

依赖使用 `github.com/pkg/sftp v1.13.9`，兼容项目 Go 1.24 基线。
未使用 v1.13.11，因其要求升级 Go 及现有 crypto 等依赖。
API 参考：[pkg/sftp](https://pkg.go.dev/github.com/pkg/sftp@v1.13.9)。

## 本次接入

- 独立 `websftp` 访问类型：关联 SSH 应用，访问端口为 0，不创建公网监听。
- 访问列表、应用创建访问和扫描结果创建访问均支持 Web SFTP，入口 `/websftp/:id`。
- 独立页面只启动 SFTP，不分配 PTY，不启动 Shell；终端会话 API 拒绝 WebSFTP。
- 文件浏览/上传复用 `webssh.files.read` / `webssh.files.upload`；独立入口的目标和凭据读取也校验文件权限。
- 主机指纹校验保留用户上下文。WebSSH 的连接时保存逻辑保持不变。
- WebSFTP 在新建访问时配置账号，去访问直接打开文件浏览器，不再展示独立连接列表或新建连接弹框。
- 记住密码为可选项：配置保存时加密存储，但不代表已验证远程登录；未记住则进入时询问。
- 编辑访问时密码只显示掩码占位，留空保留原密码。
- 一个访问配置一个账号；同一应用使用不同账号时，新建不同访问。已有多账号记录保留兼容，不批量删除。
- 用户/访问/连接绑定的 SFTP 会话注册、过期和注销清理。
- 每次请求的资源授权与读写能力检查，以及撤权中断传输。
- HTTP 文件接口、安全错误映射、操作审计与诊断标识。
- WebSSH 文件视图、进度、取消、失败状态与中英文 UI。
- 终端/文件页签共用工作区，不再使用文件弹框；切换保留终端连接、目录及预览状态。
- 可调整目录树、文件列表和侧边文本预览；路径导航、前进后退、筛选和底部状态区。
- 文件视图和 Agent 使用同一网格布局，避免打开侧栏时文件区域消失。
- 会话存储的跨用户/跨登录令牌隔离、过期与取消测试。
- 普通用户默认拒绝文件权限；浏览和上传分开授权，上传依赖浏览。

## 已知边界

- 必须支持 OpenSSH hardlink 扩展才能上传；不使用可能覆盖目标的 rename 降级。
- 远程文件系统遵循 SSH 账户权限，起始目录不是沙箱。
- 取消/断线后可能无法清理远端临时文件，错误携带临时路径供后续审计和重连清理；
  HTTP 层不得直接返回这些原始错误。不能宣称断线清理一定成功。
- 客户端库会读取完整目录，当前 10,000 项是返回条数限制，不是读取内存上限；
  大目录的有界枚举仍需解决后再开放到生产。
- HTTP 调用方必须使上传源和下载目标在取消时解除阻塞（读写期限或关闭请求体）。
- 上传成功但清理临时链接失败应呈现“已上传，清理失败”，避免误导用户重复上传。
- 原生 SSH Gateway 的 SFTP 拒绝策略保持不变。
